# EduAmigaE

**Learn Amiga E from first program to real Amiga applications.**

EduAmigaE is a bilingual (Norwegian/English) course and book project for learning the Amiga E programming language on classic Amiga systems.

The course starts from zero and progresses toward practical Amiga programming: language fundamentals, modules, data structures, system programming, Intuition/graphics, files and devices, libraries, debugging, optimization, and complete projects.

## Goals

Students should be able to:

- understand the core Amiga E language and programming model
- compile, run and debug Amiga E programs
- use modules, procedures, objects, lists and pointers confidently
- work with AmigaOS libraries and system interfaces
- build command-line and GUI applications
- understand memory, resources and Amiga-specific constraints
- read and maintain existing Amiga E source code
- complete progressively larger Amiga projects independently

## Course principles

- beginner friendly, but technically rigorous
- learn by writing and changing real programs
- explain the Amiga concepts behind the code
- Norwegian is the primary edition; English is maintained alongside it
- examples must be reproducible
- the student must not depend on private Ploos infrastructure
- a self-contained student OCI image will provide the required toolchain where legally distributable
- material is single-source Markdown and intended for web, EPUB, Kindle and PDF publication

## Planned progression

1. Introduction and development environment
2. Your first Amiga E program
3. Values, variables and expressions
4. Decisions and loops
5. Procedures and program structure
6. Strings, arrays and collections
7. Pointers and memory
8. Modules and reusable code
9. Objects and Amiga E idioms
10. Files and command-line programs
11. AmigaOS fundamentals
12. Libraries and system calls
13. Intuition and GUI programming
14. Graphics and screens
15. Input, devices and events
16. Debugging and defensive programming
17. Performance and memory discipline
18. Interoperability and existing Amiga software
19. Larger guided projects
20. Final independent project
